# Starting an eval

**Rule:** Picked up during the quiet compass 4894 cleanup. An eval is a task plus graders; a trial is one attempt, and you run several.

**Why:** Grade what the agent produced, not the steps it took to get there. Read the transcripts: a grader that passes everything is measuring nothing. A capability eval starts low; a regression eval sits near 100% and guards against backsliding. pass@k asks whether one of k tries works; pass^k asks whether all of them do. An eval is a task plus graders; a trial is one attempt, and you run several. Written down so the next agent doesn't redo it.
